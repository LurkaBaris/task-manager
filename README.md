# task-manager

Начинаем делать Task Manager:

Стэк:

React, Typescript, React Router, Vite, CSS Modules

Задача 1:

Создание проекта на Vite, настройка ts, подключение React Router, оформление структуры папок и базового лейаута

Задача 2:

Страница с экраном списка задач. Карточка задачи должна содержать: название, описание, дату создания, статус, приоритет. Для начала можно начать с верстки и подготовки нужных компонентов.

Задача 3:

Создание задачи. Добавить модальное окно с нужными полями и валидацией. Сохранение данных пока реализуем через localStorage. Если хорошо пойдет, то можно сразу попробовать использовать IndexedDB(c библиотекой idb).
