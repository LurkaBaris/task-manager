# Task Manager

Канбан-доска для управления задачами. Приложение хранит данные локально в браузере через IndexedDB, поддерживает создание, редактирование, удаление, восстановление удаленной задачи, поиск, фильтрацию, сортировку, drag and drop и импорт/экспорт доски через JSON-файл

- Редактирование и удаление задач
- Создание и удаление колонок

- Сортировка задач внутри колонок

- Drag and drop колонок
- Нормализация позиций задач при изменении порядка

- Сортировка комментариев по дате с сохранением выбранного порядка в `localStorage`
- Страница статистики по колонкам, приоритетам и типам задач
- Переключение между светлой, темной и системной цветовой темой
- Заголовок вкладки браузера для каждой страницы

- Импорт и экспорт колонок, задач, тегов, комментариев и вложений через JSON-файл
- Error Boundary и уведомления для пользовательских действий

## Drag and drop

Drag and drop реализован не только как визуальное перемещение карточек, но и как полноценная логика изменения порядка задач

Каждая колонка может иметь собственный режим сортировки: ручной порядок, новые задачи сначала или старые задачи сначала. Выбранный режим сохраняется в `localStorage`, поэтому при перетаскивании учитывается не только колонка назначения, но и текущий способ отображения задач в ней

Для ручного порядка используется поле `position`. Позиции хранятся с запасом между значениями, например `0`, `1000`, `2000`. Благодаря этому при вставке задачи между двумя соседними задачами можно выдать ей промежуточную позицию, например `1500`, без массового пересчета всех задач в IndexedDB

Когда свободного промежутка между соседними позициями становится недостаточно, запускается нормализация: задачи в колонке сортируются и получают новые позиции с нормальным шагом. Это сохраняет быстрые вставки и не дает позициям превратиться в трудно управляемый набор значений

Во время перетаскивания используется draft-состояние, чтобы интерфейс сразу показывал будущий результат перемещения. После завершения drag and drop итоговое состояние сохраняется в хранилище

## Данные приложения

Колонки, задачи, теги, комментарии и вложения сохраняются локально в IndexedDB браузера. Данные не отправляются на сервер и доступны только в текущем браузере пользователя

Настройки сортировки и выбранная цветовая тема сохраняются в `localStorage`. Поиск и фильтры хранятся в query-параметрах URL

Для переноса или резервного копирования данных можно использовать:

- `Экспорт` - выгружает текущую доску в JSON-файл
- `Импорт` - загружает доску из JSON-файла

При импорте доступны два режима:

- `Обновить` - добавляет новые данные и обновляет существующие по `id`
- `Заменить все` - полностью заменяет текущую доску данными из файла

Вложения экспортируются в формате Base64. Также поддерживается импорт старых версий backup-файлов

## Структура проекта

Проект организован по FSD:

```txt
src/app        - инициализация приложения, провайдеры, роутинг, layout
src/pages      - страницы приложения
src/widgets    - крупные UI-блоки, например доска задач, комментарии и статистика
src/features   - пользовательские сценарии: создание, редактирование, удаление, импорт, экспорт, dnd
src/entities   - бизнес-сущности: task, column, tag, task-comment
src/shared     - общие настройки и утилиты
```
